# Wordbaazi

A daily word-guessing game with its own identity — playable on the web and as a Flutter mobile app, with Google Sign-In and server-stored player stats.

```
server/   NestJS API — Google auth, game results, stats (SQLite)
web/      React + Vite web app (the playable web URL)
app/      Flutter iOS/Android app
shared/   Clean-room word lists + the generator script
SPEC.md   Shared game/API/design spec all three follow
```

## Deploy

```bash
cp .env.example .env    # set JWT_SECRET
docker compose up -d --build    # → http://localhost:7654
```

CI/CD: point a pipeline job in your Jenkins at this repo's `Jenkinsfile` (build → test → deploy → smoke test). Full instructions in [DEPLOY.md](DEPLOY.md).

## Quick start (local dev)

```bash
# 1. API (port 3000)
cd server && npm install && npm run build && npm start

# 2. Web (port 5173)
cd web && npm install && npm run dev

# 3. Mobile
cd app && flutter pub get && flutter run
```

Everything is playable immediately with **local** stats. To enable Google Sign-In and **server-side** stats, create a Google OAuth client ID and set it in `server/.env` and `web/.env` (and the Flutter platform configs) — each part's README has the exact steps.

## How it works

- A new puzzle every day at local midnight, deterministic for all players (puzzle #1 = 2026-08-25, indexed into the pre-shuffled answers list). No server needed to pick the word.
- Word lists are original: generated by `shared/generate-lists.js` from the public-domain ENABLE dictionary ranked by Norvig word-frequency data, with our own curation, ordering, and epoch. 2,000 answers, 8,636 valid guesses.
- Game state persists locally, so refreshing mid-game resumes it; one game per day.
- On finish, the result is recorded locally, and — when signed in — POSTed to `/api/games` (idempotent per user/day). The stats view (Played, Win %, Current Streak, Max Streak, guess distribution) reads `/api/stats` when signed in, local stats otherwise.
- Auth: client gets a Google ID token → `POST /api/auth/google` verifies it and returns a 30-day app JWT.
